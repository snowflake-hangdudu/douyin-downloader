抖音视频下载助手 - douyin · 常见问题

最后更新：2026-09-14 · 版本 1.0.2 · 隐私政策

本页解答使用中的常见问题。扩展完全免费，不收集用户数据。只保存你当前浏览器里已经能正常打开的公开视频。

在哪里保存？

先打开抖音网页版的当前这一条视频（地址含 /video/，或精选/搜索里点开后带 modal_id），再点页面右下角悬浮按钮。浏览器工具栏弹窗只用于预览和打开面板，实际下载在页面面板里操作。

单视频怎么下载？

  1. 打开并播放视频几秒
  2. 点击右下角悬浮按钮打开面板
  3. 选择清晰度（如 1080P / 720P / 540P）
  4. 点击「开始下载」；也可单独点「下载封面」

合集列表怎么下载？

  1. 打开属于合集的视频并播放几秒
  2. 在页面右侧点开「合集」标签，等侧栏列表出现
  3. 面板切换到「列表下载」，点击「刷新列表」
  4. 勾选要保存的集数，点击「下载已选视频」

列表会显示缩略图、标题与时长。下载期间请保持页面打开；多集会依次保存到浏览器默认下载目录。

为什么识别不到视频？

  1. 确认已经点开单条视频，而不是只停在首页或搜索列表
  2. 安装或更新扩展后，先按 F5 刷新
  3. 先播放几秒，再打开面板
  4. 搜索页需等弹窗视频加载完成后再操作

封面不对或列表不全怎么办？

  • 封面优先使用页面侧栏/卡片上的缩略图；若仍异常，刷新页面后重开面板
  • 合集列表不全时，务必先打开页面右侧「合集」标签，再点「刷新列表」
  • 插件不会自动反复请求接口，需手动刷新列表

下载失败怎么办？

  1. 扩展管理页点「重新加载」，再回视频页按 F5
  2. 换一个清晰度后重试
  3. 确认浏览器允许下载，并检查下载栏是否被拦截

文件保存在哪里？

保存到浏览器默认下载目录，默认文件名使用视频标题。打开面板底部「设置」可更换主题、选择文件名预设或编辑模板；支持 {title}、{author}、{id}、{episode}、{quality} 和 {date}。同名文件由浏览器自动添加序号。可在面板「浏览器下载记录」或浏览器自带下载管理里查看。

可以暂停、取消或关闭页面吗？

任务卡提供暂停、继续和取消；能否续传取决于服务器。浏览器接管后，刷新或关闭页面通常不会停止下载，请到「浏览器下载记录」继续管理。刷新后的面板不恢复旧任务卡。

如何确认下载成功？

面板只有在浏览器报告完成时才提示已保存。网络中断会尝试备用地址；取消、磁盘满或浏览器安全拦截不会自动重试。

为什么没有更高清晰度？

面板只展示页面真实提供且高于 360P 的清晰度，不编造更高档；若页面只提供 360P 及以下档位，会保留这些档位作为兜底。未登录或权限不足时，只会看到页面真实提供的选项。

本版不支持什么？

  • 用户页、收藏夹的批量下载
  • 直播、图文笔记
  • 绕过登录、付费或私密限制
