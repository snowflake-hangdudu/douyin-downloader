抖音视频下载助手 - douyin · 隐私政策

最后更新：2026-09-14 · 版本 1.0.1 · 常见问题

本扩展（「抖音视频下载助手 - douyin」）由个人开发者提供。我们重视您的隐私。本政策说明本扩展如何处理信息。

1. 我们收集哪些数据

我们不收集、不存储、不上传、不出售任何个人数据。

  • 不收集姓名、邮箱、账号密码
  • 不收集浏览历史并发送到第三方服务器
  • 不使用分析/追踪 SDK
  • 不含第三方广告网络；可能展示开发者公告与合作说明（静态 JSON 文本）

2. 本地处理说明

本扩展仅在您访问抖音网页版相关页面时运行。识别与保存都在您的浏览器本地完成。下载文件保存到您设备上的浏览器默认下载目录。

扩展只保存当前页面已经加载、浏览器本身可访问的公开内容，不绕过登录、付费或私密限制。单视频与合集列表下载均仅在您主动点击后开始。

面板中的设置用于在本地保存主题与文件名模板。点击「反馈邮箱」时，扩展会把固定反馈邮箱复制到剪贴板；扩展不会读取剪贴板内容。若复制不可用，会尝试打开邮件客户端。

3. 权限用途

  • activeTab / 页面脚本：识别当前抖音视频页、合集列表，并展示下载面板
  • downloads：把已获取的视频 / 封面保存到本机
  • storage：仅在本地保存公告缓存、下载偏好与评分状态
  • clipboardWrite：仅在您点击反馈邮箱按钮时复制反馈邮箱；不读取剪贴板
  • declarativeNetRequest：给封面等资源补上页面同源 Referer，避免防盗链失败
  • 配置站：读取公告、开发合作与商店评分开关（静态 JSON，不执行远程代码）

4. 第三方域名

为完成下载，扩展会在您主动保存时访问抖音页面已暴露的 CDN 地址（如 douyinvod.com、douyinpic.com 等）。这些请求仅用于获取您选择保存的媒体文件，不包含用户身份上报。
